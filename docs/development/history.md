# 開発の記録

!!! summary "要点"
    - SURGE Mark.2 は、**2025 年 6 月のモータドライバ基板の設計から始まり**、約 1 年半かけて今の形になりました。
    - 前半の 1 年は**基板とファームウェア**（モータドライバ → 制御基板 → FOC）を作り、2026 年 8 月に Raspberry Pi 5 の上位ソフトを作り直してから、**自動運転の方式を次々に足して**きました。
    - コミットは 3 つのリポジトリとこのサイトで、合わせて約 820 件です。下の年表は、その中から節目になったものを月ごとに拾ったものです。

!!! note "この記録の出どころ"
    各リポジトリの `git log`（全ブランチ）と、上位の開発記録（`PROGRESS.md`・`docs/stereo_plan.md`）から作りました（2026-11-15 時点）。
    日付はコミットの日付です。**基板の「発注」や「完成」は、製造データを作ったコミットの日付からの推定**で、実際の発注日とはずれることがあります。

## 全体の流れ

| 時期 | 中心にしたこと |
|---|---|
| 2025-06〜07 | モータドライバ基板の初版。センサなし → エンコーダでモータを回し、UART でつなぐ |
| 2025-10〜2026-04 | 制御基板（STM32）の設計。基板 V1 が動く |
| 2026-05〜07 | 制御基板 V2・V3、TC の初版。モータドライバ V4 と FOC |
| 2026-08 | Raspberry Pi 5 で上位を作り直す。最初の自動運転、地図、シミュレータ、強化学習 |
| 2026-09 | SLAM、模倣学習、駐車、分岐のあるコース、ABS |
| 2026-10 | 校正の道具と車速の推定。会場で試走 |
| 2026-11 | C による高速化、GUI の刷新、E2E 融合、前方ステレオ |
