# 用語集

このサイトで使う用語です。本文では、下線の付いた略語にマウスを乗せると、同じ説明が出ます。

## 車とモータ

| 用語 | 意味 |
|---|---|
| インホイールモータ | 車輪の中にモータを収め、車輪を直接回す構成 |
| ダイレクトドライブ（DD） | 減速機（ギア）を使わず、モータで直接車輪を回す方式。ガタ（バックラッシ）と粘りがない |
| バックラッシ | ギアの歯と歯のすき間。トルクの向きが変わるとき、すき間を詰めるまで力が伝わらない |
| BLDC | ブラシレス DC モータ。ブラシの代わりに電子回路で電流の向きを切り替えて回す |
| KV | 無負荷で 1 V あたり何 rpm 回るかを表すモータの定数 |
| 極対数 | モータの磁石の N・S の組の数。この車のモータは 7 |
| モータドライバ（MD） | マイコンの指令に従ってモータに電流を流す回路 |
| FOC（ベクトル制御） | 相電流を測り、トルクを生む成分（q 軸電流）だけを狙って流す制御 |
| q 軸電流（Iq） | トルクを生む電流の成分。トルクは Iq に比例する |
| PWM | オン・オフの時間比率で平均の電圧を作る方法 |
| シャント抵抗 | 電流を測るための小さな抵抗。両端の電圧から電流が分かる |
| ダブルウィッシュボーン | 上下 2 本のアームで車輪を支えるサスペンション |
| 据え切り | 車が止まったままハンドルを切ること |

## 制御

| 用語 | 意味 |
|---|---|
| PI 制御 | 目標との差（比例）と、差の積み重ね（積分）から操作量を決める制御 |
| TC（トラクションコントロール） | タイヤの空転を検知して駆動力を絞る |
| ABS | 制動時にタイヤがロックしないよう制動力を調整する |
| TV（トルクベクタリング） | 左右の車輪に配るトルクを変えて、曲がりやすさを調整する |
| スリップ率 | タイヤの周速と実際の車速のずれの割合 |
| カルマンフィルタ | 複数のセンサの値を、それぞれの信頼度に応じて組み合わせて推定する方法 |
| ハートビート | 「生きている」ことを示すために出し続ける合図 |

## 自動運転

| 用語 | 意味 |
|---|---|
| LiDAR | レーザーを回転させて周囲の距離を測るセンサ |
| IMU | 加速度と角速度を測るセンサ |
| SLAM | 地図の作成と、地図の中での自己位置の推定を同時に行う技術 |
| ICP | 2 つの点群を重ね合わせて、位置と向きのずれを求める方法 |
| 脱スキュー | LiDAR が 1 回転する間に車が動いたことによる点群のゆがみを補正すること |
| レーシングライン | コースを速く走るための走行ライン |
| Pure Pursuit | 少し先の目標点を狙って舵角を決める経路追従の方法 |
| MPC（モデル予測制御） | 車の動きを少し先まで予測し、最適な操作を求める制御 |
| Follow the Gap | LiDAR で最も広く空いている方向を探して進む方式 |
| E2E | センサの入力から操舵などの出力までを、1 つの学習モデルで直接つなぐ方式 |
| 模倣学習 | 人や手本の運転を真似るように学習する方法 |
| 強化学習 | 試行錯誤で、報酬が大きくなる行動を学習する方法 |
